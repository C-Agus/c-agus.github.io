Coursework · 2026

Data Structures in C++

Six data structures and tools built from scratch in C++11 for FSU's Data Structures, Algorithms, and Generic Programming course, each verified byte-for-byte against the instructor's reference programs on a Linux server.

  • Stack: C++11, g++, Linux
  • Standard: compiled warning-free with -Wall -Wextra

What I built

The six projects

Templated vector

A generic dynamic array class template with its own memory management.

Doubly linked list

Iterators, in-place reversal by swapping pointers, and safe removal while iterating.

Stack & infix-to-postfix

A stack adaptor used to convert infix expressions to postfix and evaluate them.

Binary expression tree

Builds a tree from postfix input and prints infix with the minimum parentheses needed.

Hash table & password server

A separate-chaining hash table template powering a password server that stores only hashed passwords.

Frequency analyzer

Counts characters, words, and numbers in text, using unordered_map and partial_sort for the top ten.

How I tested

Matching the reference exactly

Each project came with a reference executable. I treated it as a specification: I ran my program and the reference on the same inputs and compared the output with diff, down to trailing spaces and whether errors went to standard error. A project wasn't done until the output matched exactly.

About the code: these are graded course assignments, so the source isn't public. I'm happy to walk through the implementations in an interview.
