# c-agus.github.io

Personal portfolio for Agustin Camus, live at **https://c-agus.github.io**.

Plain HTML and CSS with no build step or dependencies, hosted on GitHub Pages.

```
index.html              home: about, projects, skills, education, contact
projects/               one page per project
assets/css/style.css    all styles (light/dark themes via CSS variables)
assets/js/theme.js      light/dark toggle
assets/img/             screenshots, favicon, social preview card
assets/Agustin_Camus_Resume.pdf
```

To preview locally: `python3 -m http.server` in this folder, then open http://localhost:8000.
